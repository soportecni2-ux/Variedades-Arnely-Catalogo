# Variedades Arnely — Catálogo digital (prototipo)

## Incluye
- Catálogo adaptable a celular y computador.
- Categorías: Celulares, Parlantes, Accesorios y Productos venezolanos.
- Búsqueda, precio en COP y botón para pedir por WhatsApp.
- Panel de demostración para agregar, editar y eliminar productos.
- Las fotos se pueden cargar desde el dispositivo.

## Antes de publicarlo para clientes
GitHub Pages sirve archivos estáticos; no proporciona por sí solo autenticación segura ni una base de datos compartida. Para un catálogo real con panel privado, conecta un backend como Supabase o Firebase, con reglas de acceso y autenticación adecuadas. No publiques este prototipo como si su panel ya fuera privado.

## Publicar la maqueta en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. Selecciona **Deploy from a branch**, elige `main` y `/ (root)`, y guarda.
5. Abre la URL que GitHub Pages genere.

Los productos iniciales son ejemplos. Reemplázalos con fotos y precios reales desde el panel de demostración.
